# 摸鱼周报 · MOYU WEEKLY 摸鱼周报生成器（上市公司年报体例）

> **摸鱼科技股份有限公司**（证券代码 002520 · 公司简称 摸鱼科技）
> 一份"一本正经胡说八道"、按**上市公司年度报告体例**编排的摸鱼周报。
> **一句大白话的一周流水账，一份像模像样的年度报告式工作摸鱼周报 PDF。**

把一周鸡毛蒜皮的工作痕迹（开了几个会、改了几版 PPT、需求又变了、周五盯着冰箱发呆）套上
上市公司年报与大厂汇报的严谨外壳，全自动写成一份 **A4 单栏中文 PDF**：有公司字标与
信息披露专用章、有证券代码与重要提示、有指标速览、目录与释义、有管理层摘要、
有全宽 KPI 表与风险矩阵、有自创职场黑话、有编号口径说明、有真实生成的图表、
有页眉页脚与「第 X 页 / 共 Y 页」，还有一个**带牙齿的「摸鱼周报质押协议」**，
最后留一个永久空白的审批签字栏。

这是一个 **Skill**，默认安装到 [WorkBuddy](https://www.workbuddy.cn/)（也兼容 Claude Code）。
你只要丢一句本周素材 + 署名，它一路做到底，交付编译好的 PDF + 可复用的 `.tex` 工程。

> 本仓库由早期内部报告模板改造而来：**输出模式（带公司标识、表格、真图的 PDF）和工具链
> （XeLaTeX / matplotlib / Chrome headless）完全保留**；核心功能与思考逻辑是「写摸鱼周报」，
> 品牌统一为「摸鱼」，场景与词汇全部换成公司 / 职场语境，
> 版式由双栏内刊式排版改为上市公司年报体例，风格仍是原来的过分严肃搞笑。
> 改造前的历史范文与旧版工程已集中归档到 `archive/legacy-paper-examples/`，仅供溯源，
> 不参与构建；`examples/` 现在只放当前年报体例的成品。

```bash

cd moyu-zhoubao-writing-main
bash install.sh          # 把 skill 链接到 ~/.workbuddy/skills/
```

默认装到**用户级** `~/.workbuddy/skills/`，所有工作区都能直接调用。其他用法：

```bash
bash install.sh --project      # 装到本仓库 .workbuddy/skills/（仅当前工作区可用）
bash install.sh --uninstall    # 移除本脚本创建的链接

```

> Windows 上用**目录 junction**（无需管理员权限），macOS / Linux 用符号链接；两者都实时
> 指向本仓库，改 `SKILL.md` 立即生效、不用重装。装好后若当前会话没出现该 skill，
> 新开一个会话刷新 skill 列表即可。
>
> 仍在用 Claude Code：`WORKBUDDY_SKILLS_DIR="$HOME/.claude/skills" bash install.sh`。

## 给任意 AI Agent / 豆包等（没有 Skill 机制时）

本 skill 的"大脑"就是纯 Markdown 说明书——**任何能读仓库、会跑脚本的 agent 都能照着做**，
不需要"安装"。让它读本仓库，然后：

> 读取 `skills/moyu-weekly/SKILL.md` 并完整遵循，帮我按其中的输入规范写一份摸鱼周报，
> 本周素材是「XXX」。

它会先读 `SKILL.md`（工作流）+ `references/style-guide.md`（文体解剖），再写正文、
用 `scripts/figure_helper.py` 出图、灌进 `assets/template/`、跑 `scripts/compile.sh` 出 PDF。

**环境依赖**：出 PDF 需要 **XeLaTeX**（TinyTeX/MacTeX）+ Python/matplotlib/numpy。
若环境没有 XeLaTeX，可走仓库范文同款等效路径：Chrome headless 打印 A4 年报 HTML，
或把 `.tex` 丢进在线 LaTeX 平台（编译器选 XeLaTeX）。

## 目录结构

```
skills/moyu-weekly/                 ← 仓库唯一的 skill
├── SKILL.md                         一句话素材 → 全自动出稿的工作流 + 输入规范
├── references/style-guide.md        文体解剖：思考逻辑对照 / 年报版式 / 流派 / 黑话 / 骨架 / 翻车清单
├── scripts/
│   ├── compile.sh                   一键编译 PDF（自动找 XeLaTeX + 补装宏包 + 中文字体降级）
│   ├── figure_helper.py             matplotlib 中文出图助手（解决方块字问题）
│   ├── make_logos.py                公司字标 / 信息披露专用章 / 占位示意图
│   ├── model.py                     示意性测算模型：KPI / 表格 / 图的唯一数字来源
│   ├── make_figs.py                 3 张真图（工时堆叠柱 / 机制闭环 / 协议流程）
│   ├── content.py                   示例摸鱼周报正文（也是仿写模板）
│   └── build_weekly.py              一份内容 → 年报体例 .tex + A4 单栏 HTML
└── assets/template/                 A4 单栏年报模板 + 公司字标 + 披露专用章 + 占位图

examples/                            当前年报体例成品：示例 PDF + 对应 .tex 工程
output/weekly-W45/                   本次示例的完整工程：.tex / .html / .pdf / 3 图 / 脚本
archive/legacy-paper-examples/       改造前的历史范文与旧版工程（仅供溯源，不参与构建）
```

## 底线（写在 skill 里的硬约束）

- **数据诚实**：用户有真实数据就用真的；没有则用**明确标注"示意性测算、未经审计"**的数字，
  绝不把测算当成真实经营数据或业绩承诺。
- **思考逻辑是摸鱼周报的**：结论先行、交付清点、在途有责任人 / 下一步 / 截止、
  风险有等级与升级路径、下周有承诺。
- **版式是年报的**：A4 单栏、封面、目录、释义、编号章节、全宽表格、页眉页脚页码、
  备查文件目录；不要退回双栏内刊式排版。
- **要有牙齿**：不止汇报，还要给一个**有真实代价 + 真行为学杠杆**的具体制度/产品。
- **戏仿分寸**：调侃普遍职场现象，靠自嘲共嘲取乐，不做针对具体个人 / 公司的恶意攻击。
