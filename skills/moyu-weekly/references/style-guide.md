## 0.5 思考逻辑对照：随手流水账 → 年报体例摸鱼周报

**这是本 skill 与普通「记一下这周干了啥」最根本的分野。文体、模板、工具都可以沿用，
但脑子要换一套。**

| 环节 | 随手记流水账时 | 写年报体例摸鱼周报时 |
|---|---|---|
| 读者 | 自己：想起啥写啥 | 上级 / 董事会：只关心"**结论是什么、做完没、卡在哪、什么时候给**" |
| 顺序 | 想到哪写到哪 | **结论先行** → 交付清点 → 在途下落 → 风险升级 → 下周承诺 → 复盘 → 制度改进 |
| 基本单位 | 一句"今天好累" | 一条"**事项 + 责任人 + 状态 + 截止 + 下一步 + 验收口径**" |
| 时间朝向 | 只写过去 | 本期交付（过去）+ 下期承诺（**未来**），且两者必须对得上 |
| 数字的意义 | 没有数字 | **KPI / 环比 / 完成率**，带统计口径、单位、责任人，并声明未经审计 |
| 空白怎么填 | 略过不写 | 标 `[待确认]` 并写明谁在什么时候补，**不许用"推进中"糊过去** |
| "解决方案" | "下周再想想" | 一个**制度 / 协议 / 产品**，要能落到下周一早上的动作 |
| 形式 | 聊天框几行字 | 封面、目录、释义、编号章节、全宽表、图表、页眉页脚页码、备查文件 |
| 结尾 | 没了 | **审批签字栏（永久留白）+ 免责声明** |
| 荒诞来自 | 内容本身 | 把一周的琐碎**披露得过分庄重、过分精确、过分不必要** |

> 一句话：**流水账让人"哦"；这份摸鱼周报让人"笑完想把它转发到部门群，然后又默默关掉"**。
> 它特有的笑点是「形式感过剩」：证券代码、重要提示、密级、版本号、审批链、环比、
> 统计口径、验收标准、备查文件，一样不缺，汇报的内容却是"三次接水、六场会、
> 一个没改完的 PPT"。

**关键心法：全程"绷住"。** 编制人永远不承认自己在开玩笑。越是荒诞的一周，
越要用最冷静、最客观、最"本期净产出经口径校准后为……"的语气说出来。
幽默不是靠"哈哈这很好笑"来制造的，而是靠**把一件小事汇报得比它值得的严肃一万倍**来制造的。

好的素材：**读者一看结论就会心一笑"这也值得出份报告？"，读完却觉得"这不就是我这一周"。**
- 开了 6 个会，没有任何一个需要我做决定 → 会议热力学与决策真空
- 消息已读不回，需求却悄悄变了 → 跨部门依赖阻塞与需求漂移
- 收藏了 14 篇"必读"，一篇没看 → 知识押金与承诺兑现率
- 进度条 99% 卡了三天 → 末端通胀与闭环势能
- 周五下午什么都没干，但摸鱼周报按时交了 → 摸鱼周报自指悖论

## 1. 黄金公式

一份合格的摸鱼周报 = **一个人人有共鸣的一周流水账** + **一套严肃到过分的披露框架** +
**一堆言之凿凿的示意性测算** + **全程绷住的披露脸** + **一个真会咬人的改进协议**。

其中「披露框架」必须包含摸鱼周报的四根柱子，缺一根就不像摸鱼周报：
**结论、交付、风险、承诺**。没有承诺项的摸鱼周报是日记，没有风险的摸鱼周报是宣传稿，
没有交付清点的摸鱼周报是随笔，没有结论的摸鱼周报是——真·摸鱼周报（最没笑点的那种）。
再加上年报的外壳（封面 / 目录 / 释义 / 编号章节 / 页码 / 备查文件），
「形式 × 内容」的反差才拉满。

## 2. 语域配比：披露腔 × 网络梗

这是最容易翻车的地方。两种语言要**编织**在一起，而不是分段。

**A. 披露骨架语（占比约 70%）** —— 提供"庄重"：
> "报告期内共识别跨部门依赖项 3 项，其中 P0 级阻塞 1 项。经口径校准，有效产出率
> 由上周的 26.4% 下降至 22.3%，主要贡献来自会议密度上行与对齐颗粒度衰减……
> 上述测算未经审计，不构成业绩承诺。"

**B. 网络梗 / 打工人吐槽（占比约 30%）** —— 提供"荒诞"，通常落在**句尾当作 punchline**：
> "……说到底就是会开完了，事没动。" · "对齐了颗粒度，没对齐进度。"
> "气氛到位，交付退位。" · "画饼不烙饼，闭环不闭眼。" · "身体在工位，灵魂在摸鱼周报里。"

**编织手法**：一个严肃的长句铺陈口径，紧跟一句大白话/网络梗把它戳破。
披露句负责"端着"，梗句负责"泄气"，一端一泄就是笑点。

> 反面（不要）：整段纯黑话（变成真·无聊年报）；或整段纯吐槽（变成朋友圈，丢了高级感）。

**词汇双语化**：核心名词第一次出现时给英文注释并首字母大写，模仿真披露文件习惯：
"摸鱼熵增 (Slack Entropy Growth)"、"对齐颗粒度衰减 (Alignment Granularity Decay)"、
"边际交付递减 (Diminishing Marginal Delivery)"。

**披露腔词库**：报告期、本期值、环比、口径校准、未经审计、业绩承诺、闭环势能、抓手、
颗粒度、水位、对齐、拉通、复盘、归因、沉淀、透传、兜底、交付物、验收标准、升级路径、
责任人、截止日期、密级、审批链、抄送范围、留痕、重大事项、备查文件、内部控制。

## 3. 三种流派：经营分析 / 管理咨询 / 组织行为

同一份流水账可以往三个方向做，先判断素材更适合哪种（也可混搭）：

| 流派 | 武器 | 适合素材 | 范例 |
|---|---|---|---|
| **经营分析派**（默认） | 主要经营指标表、环比、归因拆解、成熟度模型、风险矩阵、计划对账 | 有"工作量/进度/协作"可量化的职场一周 | 六场会决策真空、需求漂移、摸鱼周报自指悖论 |
| **管理咨询量化派** | 熵、指数衰减、logistic、阈值、相变、测算模型 | 有"物理过程"或可量化信号的一周 | 进度条 99% 的末端通胀、摸鱼熵曲线 |
| **组织行为派** | 现象学、规训、自我工位观察、存在体验、思辨 | 情感 / 关系 / 存在体验的一周 | 已读不回的一周、周五下午的时间性、工位上的自我确权 |

量化两派靠**假 KPI 和假口径**唬人；组织行为派靠**大词嫁接和思辨深挖**唬人
（把规训、时间性、自我确权硬套到"周五下午盯着冰箱发呆"上）。

## 4. 标题与报告期

**公式：`XXXX 年第 N 周工作报告` + `「大白话钩子」+ ：+ 经营分析化到过分的副标题`**

副标题的诀窍是**堆叠 2–3 个自创或高级术语，用逗号并列**，模仿真披露文件那种
"A、B 与 C 的经营分析及内控改进建议"的句式。

范例：
- `2026 年第 45 周工作报告 · 开了六个会，没一个需要我：会议热力学、决策真空与对齐颗粒度衰减的周度归因`
- `2026 年第 45 周工作报告 · 进度条卡在 99% 的三天：末端通胀、闭环势能衰减与承诺兑现率的测算分析`
- `2026 年第 45 周工作报告 · 收藏了 14 篇必读，一篇没看：知识押金缺失下的边际交付递减`
- `2026 年第 45 周工作报告 · 本期未发生任何事：摸鱼周报自指悖论与零增量周期的口径校准`

要素：报告名庄重，口语钩子负责共鸣，披露腔到过分的副标负责唬人；
副标里至少有一个你自己造的黑话。封面另列报告期、周次、披露日期。

## 5. 封面与报头

这是固定的"摸鱼宇宙"彩蛋区，几乎每份都玩。可给填报人用真名真部门，
或默认生成一套公司化的：

- **公司**：`摸鱼科技股份有限公司 / MOYU TECHNOLOGY CO., LTD.`，
  证券代码 `002520`、公司简称 `摸鱼科技` —— 假装是一家真的上市公司。
- **部门 / 工位**：`协同赋能事业部 / 数字效能部 · 中国 · 摸鱼科技园 B-14 工位`。
- **编制人**：摸小鱼、明天一定做 之类的中英混搭 ID。
- **密级 / 版本 / 审批链**：`内部公开（其实没人看）`、
  `版本 v0.9（第 7 次修订，改动内容为把「推进中」改成「持续推进中」）`、
  `审批链：自提 → 自审 → 自动抄送自己`。
- **资助 / 预算**：`本报表由员工创新预算资助（项目编号：5201314）`。
- **补充**：`本报表含随文附件：示意性测算脚本与会议纪要摘录`。
- **右下角**：信息披露专用章（红色圆章），是「像年报」的第一眼证据。

保持简短，几行点到为止——这里是彩蛋，不是正文。用户给了真名真部门就**逐字**填，别替换。

## 6. 重要提示 / 管理层摘要 / 释义 / 填报声明

顶部四件套，严格模仿上市公司年报。

**重要提示**：封面或前置页的醒目框，用董事会声明的语气**把戏仿定位和数据口径说清楚**：
> "本公司董事会及全体填报人保证本报告所载内容不存在虚假记载、误导性陈述或重大遗漏……
> 本报告全部指标均为示意性测算，未经审计，不构成任何业绩承诺或经营预测。"

**管理层摘要 / EXECUTIVE SUMMARY**：用「结论 — 产出 — 风险 — 下周」四段式
（**不是目的·方法·结果·结论**），每段一两句。**这是全文的浓缩笑点集**——
要在这里就抛出核心黑话和最炸的假结论。
> 结论：本期未发生任何需要写进报告的事，但本报告按时完成，构成唯一可验证交付物。
> 产出：共清点交付物 4 项，其中 3 项为会议纪要，1 项为对本报告的撰写。
> 风险：跨部门依赖项 1 项升级为 P0，症结为对方已读不回。
> 下周：提交 3 条承诺项，均附责任人与验收口径，并接入「摸鱼周报质押协议」进行约束。

**释义 / DEFINITIONS**：年报必备。把自创黑话做成「词语 / 含义」两列表，
一半正经一半梗，读起来像真的术语表：
> 摸鱼周报自指悖论：把「撰写本报告」计为交付物时，账面产出被系统性抬高的现象。
> 决策真空：会议数量与需要本填报人做出的决策数量在统计上完全解耦的状态。

**填报声明 / ATTESTATION**：一段。真年报用它讲"编制责任"，这里**再抖一个自嘲包袱**。
> "本报表全部填报过程均在'硬撑着认真上班'的前提下完成，全程瞪大双眼，脑袋放空，
> 未出现任何形式的精神离席。编制人对统计口径拥有最终解释权，因为口径也是编制人自己定的。"

## 7. 自创职场黑话

**这是本文体的灵魂。** 一份好摸鱼周报至少有 **1 个招牌大概念 + 2–3 个配套小指标**。

**招牌概念**：给一周的琐碎起一个唬人的、有画面感的名字，配英文。
- 摸鱼熵增 (Slack Entropy Growth) · 决策真空 (Decision Vacuum) · 摸鱼周报自指悖论
  (Weekly Self-Reference Paradox) · 对齐颗粒度衰减 · 闭环势能衰减 · 末端通胀

**配套量化指标**：造几个"指数/系数/率"，让摸鱼周报显得可测量。
- 有效产出率 (Effective Output Ratio) · 会议密度指数 (Meeting Density Index) ·
  承诺兑现率 (Commitment Fulfillment Rate) · 需求漂移系数 · 已读不回半衰期

**造词方法**：
1. 拿一个**理科 / 管理硬词**（熵、真空、势能、漂移、通胀、闭环、颗粒度、阈值、对齐）
2. 嫁接到**日常对象**上（开会、接水、收藏、已读不回、下周再说）
3. = 摸鱼熵增、决策真空、知识押金缺口、努力-摆烂量子叠加

术语一旦造出来，**全文反复使用、当真名词用**，写进「释义」表，给它下"定义"、
编号、写进口径说明和 KPI 表。

## 8. 口径与操作规程军火库

在「备查文件 / 编制口径」里，一本正经地描述你**根本没做**的统计方法。
关键是给平平无奇的日常观察起一个专业方法名，并"严肃"描述其操作规程。

现成的假方法（可直接改造）：
- **自我工位观察法 (Self-Desk Observation)**：即"我拿自己这一周举例"的专业说法。
- **工位凝视法**：长时间盯着水杯与屏幕，记录"打开冰箱却忘记要拿什么"引发的心理波动。
- **聊天框证据链追踪法**：在对方不回消息期间观察其公开动态，判断其是否具备回复能力。
- **会议纪要语义密度分析** / **日历考古学** / **界面线索观察法** / **摸鱼周报对账法**。

方法名可以尽情"唬人"，但**涉及具体样本量与流程时，守 §9 的红线**：真做了才说
"统计 6 场会议录音"；没做就用"示意性观察""基于测算模型的推演"这类不冒充
审计数据的措辞。

**自嘲式口径声明**（很加分）：坦白方法的不严谨，但用披露语气说：
> "上述材料并非统计意义上的随机抽样，而是一组具有高度可识别性和可复现性的
> 职场场景。只要一个人曾在周五下午盯过进度条，便大概率具备复现条件。"

## 9. 数据与证据：诚实红线

KPI 是经营分析 / 咨询流派的"实锤"，但**这里有一条不能越过的红线**：本文体的笑点来自
**荒诞的框架和概念**，不来自**把编造的数字伪装成真实经营数据**。文中任何数字，读者都
应能判断它是真采集的、还是示意性测算的。按两种情况处理。

### 情况 A · 用户带来了真实数据（优先！）

用户若给了真实数据、会议日历、git log、打卡记录、工单导出——**用真的**：
- 老老实实统计，所有 KPI、表格、图都从真实数据算出来，一个数字都不编。
- 戏仿只体现在**外壳**：给真实统计套上唬人的黑话、庄重章节、夸张解读。例如
  真日历显示"6 场会共 7.5 小时"，就把 7.5 郑重命名为"会议密度指数 MDI = 7.5 h/期"，
  一本正经讨论其对有效产出率的边际侵蚀。
- 真实数据 + 荒诞框架 = 最高级的效果，因为它**真的站得住**。

### 情况 B · 用户没有数据（默认）

不要写"假数据"，而是写**公开标注的示意性测算数据**——这正是戏仿披露文件的做法
（范文原话："全部数值均由测算模型生成，未经审计"）。
全文自带戏仿定位、重要提示和结尾免责声明，**明标"示意/测算"不是欺骗，而是坦诚**。

- 用**测算模型**产生数字：先写下一个（半开玩笑的）模型假设，再由模型"算"出结果。
  数字于是有了来处，而非凭空捏造。例如设有效产出率随会议时长按
  $E(m)=E_0 e^{-\lambda m}$ 衰减，由模型生成"会议 7.5 h 时产出率降至 22.3%"这条曲线——
  图、表、正文都是同一个模型真算出来的。
- **在文中点明其性质**：用"示意性测算""未经审计""基于测算模型的推演""不构成业绩承诺"
  等措辞，至少在重要提示 / 图表标题 / 口径说明 / 免责声明里说明一次。**绝不**写
  "我们统计了 1247 份打卡记录"这种把测算伪装成实测的句子——除非用户真有那 1247 份。
- 形式仍可以很"披露"：环比、统计口径、阈值、完成率照用，只要它们是**模型的
  输出**而非**捏造的实测**。区别在诚实标注，不在放弃精确。

### 通用手法（A、B 都适用）

- **KPI 仪表盘**：指标 × 本期值 × 环比 × 统计口径 / 责任人，全宽表、深色表头。
- **前后对比表**：传统做法 vs 本协议（数据来自真实分析或标注的测算）。
- **方法名**：真做了对应分析才声称做了（归因拆解、回归、方差分析）；
  没真做就用"测算模型""示意性推演"这类诚实措辞。
- **一句话神结论**：把结果翻译成大白话暴击（"会开得越多，事动得越少"）。
- **免责声明兜底**：结尾统一声明数据来自示意性测算、未经审计，给整篇数字定性。

> 一句话红线：**真的就说真的，编的就标"示意/测算"。永远不把测算数字说成经审计的
> 真实经营数据，更不写成业绩承诺。**

## 10. 口径说明军火库

经营分析 / 咨询流派的门面，也是**情况 B 生成"示意数据"的正当来源**——数字从口径来，
不是凭空编。公式**不必真的成立**，但要**符号自洽、排版正经、给出定义**。

配方：
1. 设一个变量代表日常量（m = 会议时长；n = 已完成事项数；w = 编制报告耗时）。
2. 套一个真实存在的数学形式（指数衰减 `E(m)=E0·e^{−λm}`、香农熵 `H=−Σp_i log p_i`、
   logistic 兑现率 `R=1/(1+e^{−u/θ})`、积分、博弈树）。
3. 给每个符号写一句"定义"，编号 `口径 1 / 口径 2`，并在正文引用 `如口径 (1) 所示`。

范例（摸鱼熵）：
> **口径 2（摸鱼熵）** 定义本期注意力分布的摸鱼熵为 $H=-\sum_{i=1}^{k} p_i \ln p_i$，
> 其中 $p_i$ 为第 $i$ 类活动（会议 / 交付 / 接水 / 刷手机 / 编制摸鱼周报）所占工时比例，
> $k=5$。当注意力均匀分散时 $H\to\ln k$，模型判定该期"忙且空转"。

LaTeX 模板已内置 `equation` 示例；HTML 渲染成带「计算口径 (N)」标签的浅底说明框，
不是内部刊物那种右侧编号公式。`model.py` 是这些口径的可执行版本，**数字只从它来**。

## 11. 图表：每篇都要有真图与真表

**每份摸鱼周报都应该有至少一张真正画出来的图**（不是模板自带的占位图 `fig1.png`）。图是
报告"像那么回事"的关键门面。**表也是年报的命**：至少一张全宽 KPI 表，最好再有风险矩阵
与前后对比表。

**图里的数从哪来，同样守 §9 的红线**：
- 情况 A（有真实数据）：图直接画真实数据（工时分摊、逐日分布、对比）。
- 情况 B（无数据）：图画**测算模型的输出**或**示意曲线**，并在 caption 里标明
  "示意性测算，未经审计"。图和它背后的数是同一个模型算出来的，自洽即可。

**怎么画**（用内置助手，保证中文不乱码）：
- matplotlib 默认无中文字体，中文标签会变成方块 □□□。**务必先** `from figure_helper
  import setup_cjk; setup_cjk()` 再画图——它会自动挑本机可用的中文字体并套上披露风格。
- 存成 `fig1.png`（`dpi=300, bbox_inches="tight"`），模板已经 `\includegraphics` 它。
- 年报是 **A4 单栏**，图可占 60%~85% 页宽居中，字号可读、不堆砌；
  配色用公司深蓝 `#12345A` / 红 `#B02424`。
- 常见图型：堆叠柱状（工时去向）、函数曲线（摸鱼熵 / 进度条通胀 / 承诺兑现率）、
  机制闭环图、质押协议流程图。挑最能"一眼看懂核心笑点"的那种。
- 小坑：宋体（Songti SC）等字体缺 en-dash「–」字形，标签区间用 ASCII 连字符
  「-」或波浪号「~」写（`0-50%` / `0~50%`），别用「–」。环形流程图用 `FancyArrowPatch`
  时 `shrinkA/shrinkB` 单位是 point，别设太大，否则箭头会被缩成孤立小三角。

caption 也是抖包袱的地方（范文："用上面的口径校准了一晚上，结果第二天才发现口径也是我定的"）。

## 12. 年报章节骨架

按**上市公司年度报告体例**排序，不是工作日志顺序，也不是双栏内刊排版。
标 ★ 的是常用的"加料"节，靠它们用新内容扩页，而不是重复灌水：

```
封面                                   —— 公司标识 / 证券代码 / 大标题 / 副标题 / 报告期
                                           / 4 张指标速览卡 / 重要提示 / 编制信息 / 披露专用章
目录  CONTENTS                          —— 编号章节 + 英文栏名 + 点线
释义  DEFINITIONS                       —— 黑话 → 含义两列表
管理层摘要  EXECUTIVE SUMMARY            —— 结论·产出·风险·下周（不是目的·方法·结果·结论）
填报声明  ATTESTATION
第一节  公司基本情况与报告期概览          —— 主营业务、工位与人员、交付物清点
第二节  主要指标与统计口径                —— 全宽 KPI 表 + 环比 + 图 1
第三节  管理层讨论与分析 ★               —— 深挖症结、抛黑话、套理论；可拆 2-3 小节
          · 口径说明框（编号 + 定义）
          · 上期对账 / 同业披露对照 ★    —— 半真半假引上期报告逐条对账
          · 机制闭环图
第四节  风险因素与内部控制                —— 风险矩阵：等级 + 责任人 + 截止 + 升级路径
第五节  重大事项：改进协议 ◎              —— 命名机制 + 组件 + 流程图 + 前后对比表 + 示意效果
          · 局限与口径说明 ★
第六节  下周经营计划与董事会结论          —— 承诺项（责任人/截止/验收）+ 第一二三…结论
                                           + 审批签字栏空白模板（永久留白）
第七节  备查文件目录与附录 ★             —— 编制口径与操作规程、工程附件、致谢、备查文件
免责声明  DISCLAIMER                    —— 戏仿定位 + 示意性测算 + 不构成业绩承诺
页眉：公司名 · 报告名 / 证券代码
页脚：示意性测算，未经审计 · 文体性戏仿 / 第 X 页 / 共 Y 页
```

◎ **改进协议节是本刊的招牌价值**——见下方专节。不止汇报，还要给一个能用的制度。

**管理层摘要的固定套路**（几乎每篇都用，很好用）：
1. 生动描述这一周（可用一个具体到夸张的场景开场，如"周五 17:43，进度条停在 99%，
   填报人第三次打开冰箱，确认里面没有新的结论"）。
2. 一句**结论先行**，自带反转。
3. 三个分项：产出清点 / 风险升级 / 下周承诺，各自点出数字（守 §9）。
4. 全文结构导览 + 一句自嘲。

**流派变体**：
- 组织行为派可把小节标题写成叙事式（"3.1 你开始不知道自己在等什么"）。
- 经营分析派可把「主要指标」提前，含"测算模型设置""口径变更说明"。
- 管理咨询派务必保留 KPI 表与风险矩阵，这是它的门面。

## 12.5 改进协议：不止汇报，还要给牙齿 ◎

这是本刊区别于普通吐槽的地方：**汇报完问题后，郑重其事地提出一套"制度 / 协议"。**
它必须半严肃——表面是煞有介事的内控方案，**内核却藏着一个读者真能带走、真能用的视角**。
纯搞笑的假方案没有价值；有洞见的方案才让人"笑完还想收藏（然后吃灰）"。

**怎么让方案"有料"**：先想清楚这个职场问题的**真实症结**是什么，方案就针对那个症结。
- 摸鱼周报写满"推进中"的症结 = 承诺零成本、零兑现 → 方案就给承诺**加上成本与兑现核验**。
- 收藏夹吃灰的症结 = 收藏零成本 → 方案就给收藏重新"加上成本与承诺"。
- 会议决策真空的症结 = 开会无产出锚定 → 方案就给会议"计价 / 限时 / 产出锚定"。

### 最重要的一条：把抽象原则落成一个"有牙齿的具体机制/产品" ⚙️

抽象原则（"给承诺加约束"）不好记、不够狠、不像方案。**真正出彩的方案，是把那条原则
实例化成一个具体的、能想象出画面的、真的会咬你一口的东西**——一个协议、一个 App、
一份制度、一种仪式。判断标准四条：

1. **能落成产品/画面**：读者能一眼看到它"长什么样、怎么用"。不是"建议大家兑现承诺"，
   而是"提交一条下周计划，就同时质押 5 元"。抽象 → 具体，是从平庸到出彩的关键一跃。
2. **装上"牙齿"（真实代价）**：核心是一个**真会咬人**的机制——让"不兑现"变得有代价。
   代价可以是**钱、损失、社死、物理摩擦、时间**。没有牙齿的方案（"设个提醒吧"）没有力量。
3. **背后是真实行为学杠杆**：那口"牙齿"要能点到一个真名词——**承诺装置**（commitment
   device）、**损失厌恶**（loss aversion）、沉没成本、社会监督、预付押金。**这层真杠杆
   就是方案的"料"**：读者笑完能学到一个真的能用的机制。
4. **荒诞但自洽（把真办法推到极端）**：机制可以夸张到好笑，但**每一步都要从目标顺理成章
   推出来**。笑点来自"把一个真办法推到荒谬的极端"，不是随机乱设。

> **目标质量范例**（记住这个手感）：针对"下周计划从不兑现"，设计一份协议——
> **提交一条下周计划，就同时质押 5 元**；下周五复盘未按时兑现，这 5 元立即被罚没，
> 强制**转存一份 20 年定期存单**，并把"未兑现清单"自动抄送全组摸鱼周报页脚
> （"你没做完的事，替你把钱锁进了时间的保险柜，20 年后连本带息还给那个更自律的你"）。
> —— 内核是**押金式承诺装置 + 损失厌恶 + 社会可见性**（真杠杆，stickK/Beeminder 早已
> 验证有效），外壳荒诞好记（5 元、20 年定期、罚没、全组公示）。这，就是一个
> "有牙齿的具体机制"该有的样子。对比之下，只说"加强计划管理"就太温、太抽象了。

**方案节的标准配置**（写成正经的"重大事项"）：
1. **一个杀手锏机制当主角**（上面四条），给它起个产品名 + 学名 + 英文缩写更唬人
   （如 WDP / Weekly Deposit Protocol）。
2. **把它讲清楚**：怎么提交、押什么、逾期怎么罚、成功怎么退——像真在介绍一个制度。
   可再配 2–3 个支撑组件，但它们是为这一个核心机制服务，不是平摊的 tips 清单。
3. **一张机制/流程图**（fig）：画出这个协议怎么运转、怎么打断"写满推进中"的恶性循环。
4. **一张前后对比表**（table）：传统摸鱼周报 vs 本协议（目标列加粗取胜）。
5. **示意性预期效果**：给出"用了之后承诺兑现率如何改善"——**严守 §9 红线**，
   标"示意性测算/未经审计"，数字从同一个模型算出来。
6. **戏仿分寸**：允许一两个荒诞组件（20 年定期、自动抄送），但整体让读者觉得"还真能试试"。

**一句话**：一周要好笑，协议要**具体、有牙齿、且背后是个真机制**——这才对得起"摸鱼周报提供价值"。

## 14. 质量标准与常见翻车

**好摸鱼周报的标准**：
- [ ] 素材是**真日常、真共鸣**的一周小事，不是宏大议题，也不是真·业绩汇报。
- [ ] **思考逻辑是摸鱼周报的**：结论先行、交付清点、在途有下落、风险有等级、下周有承诺，
      每条带责任人 / 进度 / 截止（§0.5）。
- [ ] **版式是年报的**：A4 单栏、封面、证券代码、重要提示、指标速览、目录、释义、
      编号章节、全宽深色表头表格、页眉页脚与「第 X 页 / 共 Y 页」、备查文件。
- [ ] 有 **1 个招牌自创黑话** + 至少 2 个配套指标，写进释义表并全文当真名词反复用。
- [ ] 形式**全程绷住**：像素级模仿真披露文件，编制人从不"出戏"承认在搞笑。
- [ ] 披露腔与网络梗**编织**出现，梗多落在句尾当 punchline。
- [ ] **有真正画出来的图 + 至少一张全宽 KPI 表**（真实数据 or 测算模型输出，非占位图）。
- [ ] 证据**守诚实红线**：真数据就用真的；测算数据明标"示意/未经审计"，绝不冒充经营数据。
- [ ] 有**具体、精确的证据**（KPI 带环比和统计口径 / 口径说明带定义和编号 / 大词硬套且自洽）。
- [ ] **有一个"有牙齿的具体机制/产品"式改进协议**（有真实代价 + 真行为学杠杆），
      含机制图 + 前后对比表，别停在抽象原则或温吞 tips。◎
- [ ] 摘要里承诺的、正文里兑现的、下周计划里写的，三者对得上。
- [ ] 读完让人"会心一笑 + 这不就是我这一周 + 还真能试试"。

**常见翻车**：
- ❌ **退回双栏内刊式排版**：又变成窄栏、页眉 logo、右侧编号公式 → 一眼像内部简报，
      年报感全无。要 A4 单栏 + 封面 + 页码。
- ❌ **写成真·无聊年报**：只有流水账和"顺利完成"，没有形式反差 → 没笑点。
- ❌ **太玩梗出戏**：通篇段子、狂发"哈哈"、编制人跳出来点评 → 丢了高级感，变朋友圈文案。
- ❌ **梗的堆砌**：网络热词密度过高、与披露口径无关 → 廉价。梗要精准服务于反差。
- ❌ **黑话不落地**：造了术语却不用、不定义、不量化、不写进释义 → 唬人失败。
- ❌ **在途项没有下落**：只写"推进中 / 持续跟进"，没有责任人、没有下一步、没有截止 →
      这是摸鱼周报特有的塌方。
- ❌ **格式塌方**：缺封面 / 目录 / 释义 / 重要提示 / 页码，章节不编号、表格窄栏 → 一眼出戏。
- ❌ **把测算当实测**：越过 §9 红线，凭空捏造"我们统计了 N 份打卡记录"却根本没数据 →
