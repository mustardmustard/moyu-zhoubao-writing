# MOYU WEEKLY 摸鱼周报生成器（摸鱼周报 · 上市公司年报体例）

帮填报人把一周的流水账，变成一份 **摸鱼科技股份有限公司《XXXX 年第 N 周工作报告》**，
按**上市公司年度报告体例**编排，编译成 A4 单栏 PDF：有公司标识与信息披露专用章、
有证券代码与重要提示、有目录与释义、有深色章节头、有全宽 KPI 表与风险矩阵、
有真实画出来的图、有编号口径说明、有页眉页脚和「第 X 页 / 共 Y 页」，
还有一个带牙齿的内控改进协议。

玩法只有一句话：**用上市公司年报 / 大厂汇报的严谨外壳，一本正经地汇报一件鸡毛蒜皮的
一周。** 全部的高级感和笑点都来自「形式的庄重 × 对象的荒诞」的反差。你的任务不是真写年报，
也不是写段子，而是精准踩在这条反差线上。

> **思考逻辑必须是摸鱼周报的，不是调研报告式的**（详见
> [references/style-guide.md](references/style-guide.md) §0.5）：
> 「**结论先行 → 交付物清点 → 在途项交代下落 → 风险升级 → 下周承诺 → 复盘机制 → 制度改进**」。
> 读者是上级，最怕「看起来很忙但没结论」。所以全程的顺序、栏目、指标、责任人、截止日期，
> 都要按经营披露走，只是每一格都被填得过分庄重、过分精确、过分不必要。

## 交付目标

零门槛、全自动：用户在**一段提示词里**给出本周素材和署名信息，你一路做到底，最终交付一个
**编译好的 PDF** + 可复用的 `.tex` / 内容源工程。除非用户主动要求参与，否则不要中途反复
提问——直接产出，产出后再让用户提修改意见。

## 输入规范（从提示词里读这些字段）

**只有「本周素材」是必需的；其余字段缺了就用默认值，绝不为了补齐信息而中断流程。**
给了就照单全收，尤其公司/署名类字段要原样填进封面。

| 字段 | 必要性 | 缺省处理 |
|---|---|---|
| **本周素材 / 流水账** | ✅ 必填 | 无则这才需要问用户：这周大概干了啥、没干啥（一两句大白话即可） |
| **编制人 / 署名**（可多个） | ★ 强烈建议 | 缺则用「摸小鱼、明天一定做」式化名 |
| **公司 / 部门 / 工位** | ★ 强烈建议 | 缺则 `摸鱼科技股份有限公司 · 协同赋能事业部 / B-14 工位` |
| **联络邮箱 / 抄送链** | ★ 建议 | 缺则用 `moyu@example.com` 式假邮箱 |
| 周期 / 周次 / 披露日期 | 选填 | 默认本周一 ~ 本周日，编号 `XXXX 年第 N 周` |
| 证券代码 / 公司简称 | 选填 | 默认 `002520 / 摸鱼科技` |
| 密级 / 审批链 / 版本号 | 选填 | 默认 `内部公开（其实没人看）`、审批链三级、版本 v0.9 |
| 流派（经营分析 / 管理咨询 / 组织行为） | 选填 | 默认按素材自动判定（style-guide §3） |
| 核心结论 / 想汇报的那句话 | 选填 | 默认由你从素材提炼 |
| 真实数据 / 附件 | 选填 | 默认走「示意性测算、未经审计」（见步骤 1.5 红线） |
| 篇幅 | 选填 | 默认 A4 单栏 7–9 页（含封面与前置页） |
| 梗浓度 / 面向人群 / 语气 | 选填 | 默认适中，披露腔与梗 7:3 |

**为什么署名要用户给**：交摸鱼周报的人通常要署真名真部门，AI 无从编造。所以编制人、部门、
邮箱一旦在提示词里出现，就**原样、逐字**填进 `COMPANY` 与封面，不要替换成化名。

**给填报人的填空模板**（可直接发给他们照填）：

```
用摸鱼周报帮我写一份摸鱼周报。

编制人：<你的名字>[、<协作人>]
公司/部门/工位：<公司名 / 部门 / 工位号>
邮箱：<联络邮箱>
（以下选填，不填走默认）
周期：<默认本周>
证券代码/公司简称：<默认 002520 / 摸鱼科技>
核心结论：<你特别想汇报的那句话>
数据：<有会议日历 / git log 就说明或附上，没有留空→用示意性测算>
```

极简版：`用摸鱼周报写一份关于「这周只完成了呼吸和三次接水」的摸鱼周报`。

## 工作流程

### 步骤 0 · 先读透文体与版式

**动手前必须完整阅读 [references/style-guide.md](references/style-guide.md)。** 它是这个文体的
解剖图：思考逻辑、黄金公式、披露腔 × 网络梗的配比、三大流派、标题/封面/重要提示/释义/
管理层摘要/职场黑话/假口径/示意性测算/假公式的军火库、年报章节骨架、以及质量标准与翻车清单。

### 步骤 1 · 读字段 + 立骨架（心里想清楚，不必都问用户）

按**输入规范**抽取字段，然后按**摸鱼周报的思考逻辑**定下这几样再动笔：

- **公司信息**：公司全称、英文名、证券代码、简称、报告期、披露日期、地址、编制人、版本、密级、
  审批链、资助（用 `员工创新预算（项目编号：5201314）` 式 corporate 彩蛋）。
- **流派**：经营分析派 / 管理咨询量化派 / 组织行为派。
- **一句话结论**：结论先行且自带反转（如「本期未发生任何需要写进报告的事，但报告按时完成了」）。
- **章节清单**（年报体例，不是工作日志骨架）：封面 → 重要提示 → 目录 → 释义 → 管理层摘要 →
  第一节 公司基本情况与报告期概览 → 第二节 主要指标与统计口径 → 第三节 管理层讨论与分析 →
  第四节 风险因素与内部控制 → 第五节 重大事项（改进协议）→ 第六节 下周经营计划与董事会结论 →
  第七节 备查文件目录与附录 → 免责声明。
- **KPI 仪表盘** 3–6 个指标 + 封面 4 张指标速览卡：会议时长、有效产出率、摸鱼熵、需求变更
  次数、闭环率……带环比、单位、统计口径与责任人。
- **招牌自创黑话** 1 个 + 配套指标 2–3 个，都配英文（如「摸鱼熵增 (Slack Entropy
  Growth)」「对齐颗粒度衰减」）；并写进「释义」表，当真名词用。
- **标题**：`XXXX 年第 N 周工作报告` + `「大白话钩子」：「塞满膨胀名词的经营分析副标题」`。
- **改进协议 ◎（招牌，必做）**：先想清症结（承诺零成本、兑现零核验），再把对策落成一个
  **有牙齿的具体机制/制度**——提交下周计划即质押 5 元，逾期罚没转 20 年定期 + 全组页脚公示；
  背后是承诺装置 / 损失厌恶 / 社会可见性。荒诞但自洽。

### 步骤 1.5 · 数据：先看用户有没有（诚实红线）⚠️

- 用户**给了真实数据/会议日历/git log/工单导出** → 用真的，老实统计，所有 KPI、表格、
  图都从真实数据算出来；戏仿只放在「外壳」（披露体例、黑话、解读、协议）。
- 用户**没有数据（默认）** → 不要捏造实测，而是用**明确标注「示意性测算、未经审计、
  非真实经营数据」**的数字：先写个（半开玩笑的）测算模型，让数字从模型算出来，并在
  重要提示、图表标题、口径说明或免责声明里点明。
- **红线**：真的就说真的，编的就标「示意/测算」，**永远不把测算数字说成真实经营数据或
  经审计数据**。笑点来自荒诞框架，不来自谎称有业绩。

### 步骤 2 · 写全文（中文）

按年报章节骨架写（style-guide §12），全程"绷住"、绝不出戏：
**封面**（公司标识 + 证券代码 + 大标题 + 副标题 + 报告期 + 指标速览 + 重要提示 + 编制信息 +
披露专用章）→ **目录**（编号章节 + 英文栏名）→ **释义**（黑话→含义表）→
**管理层摘要**（结论·产出·风险·下周，不是目的·方法·结果·结论）→ **第一节**（经营情况 +
交付物清单，每条带交付物形态与验收口径）→ **第二节**（KPI 表 + 真图 + 口径）→
**第三节**（深挖症结 + 抛黑话 + 编号口径说明 + 同业/上期对照 + 机制图）→
**第四节**（风险矩阵：等级 + 责任人 + 截止 + 升级路径）→ **第五节**（重大事项：命名机制 +
组件 + 流程图 + 前后对比表 + 示意效果 + 局限与口径说明）→ **第六节**（下周承诺项 +
第一二三…结论 + 永久留白的审批签字栏表）→ **第七节**（编制口径、工程附件、致谢、
备查文件目录）→ **免责声明**。

摘要里承诺的、正文里兑现的、下周计划里写的，三者必须对齐。**别把「研究问题/本文贡献/
材料与方法」那一套搬进来**——披露文件要的是「谁、做完没、卡在哪、什么时候给」。

**靠"内容"扩页，绝不靠重复灌水**（注水会让它变成真·无聊年报）。增量都要是新角度或新料：
上期对账、同业披露对照、机制复盘拆 2–3 小节、多一张图表或多一条口径说明、
把编制口径与操作规程写细。披露腔与网络梗要**编织**，梗多落在句尾当 punchline。

### 步骤 3 · 灌进年报模板

模板在 [assets/template/](assets/template/)：`ANNUAL-Template.tex` + `LOGO1.png`
`LOGO2.png` `fig1.png`（公司字标、信息披露专用章、占位示意图）。渲染脚本在 [scripts/](scripts/)。

**推荐走「一份内容源 + 两份渲染」的流水线**：

1. 在当前工作目录建一个输出文件夹（用周期起个短名，如 `W-2026-45/`），把
   `assets/template/` 的 4 个文件和 `scripts/` 的全部脚本拷进去。
2. **只改 `content.py`**：唯一正文来源，字段为 `COMPANY / TITLE / SUBTITLE / REPORT_KIND /
   NOTICE / HIGHLIGHTS / GLOSSARY / EXEC_SUMMARY / ATTESTATION / SECTIONS / APPENDIX /
   DOCUMENTS / DISCLAIMER`。行内标记 `[[...]]`=粗体、`((...))`=斜体、`_{...}` / `^{...}`=上下标；
   普通文本里的 `% & _ #` 会自动转义。
3. `model.py` 是唯一数字来源（示意性测算模型）。KPI、表格、图、正文引用的数字**都必须
   从它算出**，改参数即可，别在正文里手写数字（守步骤 1.5 红线）。
4. 跑 `python make_figs.py` 出 3 张真图；跑 `python build_weekly.py`，它会同时产出
   `<stem>.tex`（单栏 corporate report + xeCJK）与 `<stem>.html`（A4 年报版式），两份一致。

也支持**直接编辑 .tex**：复制 `ANNUAL-Template.tex` 为 `<文件名>.tex`，只替换占位文字，
保留导言区、字体设置、页眉页脚、封面 `titlepage`、`\tableofcontents` 等结构。
占位符一看即知（"这里是摸鱼周报标题，请替换为…"）。

- 章节标题保持 `第 N 节 + 中文 + 英文栏名`。**加粗用 `\textbf{}`，别用 Markdown 的
  `**...**`**；同理 `%` 要写 `\%`。
- **口径说明**：改模板 `equation` 示例的符号即可；经营分析/咨询派务必放至少一条带定义和
  编号的口径（style-guide §10），它也常是「示意性测算」数字的来源。
- **表格**：全宽、深色表头、目标列加粗取胜，caption 写「表 N　标题」，表下附口径注。

需要换公司标识时跑 `python make_logos.py`（仍用 `figure_helper.py` 的中文出图助手），
它会重画 `LOGO1.png` / `LOGO2.png` 并重置 `fig1.png` 占位图；随后务必再跑 `make_figs.py`
把占位图换成真图。

### 步骤 3.5 · 生成真图（必做，别用占位图）📊

**每份报告都要有至少一张真正画出来的 `fig1.png`**，不能留占位图（style-guide §11）。

用内置助手保证中文标签不乱码——**画图前先 import 它**：

```python
import sys; sys.path.insert(0, "<输出文件夹>")   # figure_helper.py 已拷到这里
from figure_helper import setup_cjk
setup_cjk()                     # 自动挑本机中文字体 + 套披露文件风格
import matplotlib.pyplot as plt
# ...按本期主题画图...
plt.savefig("<输出文件夹>/fig1.png", dpi=300, bbox_inches="tight")
```

- `scripts/make_figs.py` 是仿写好的三张图：工时去向堆叠柱 + 有效产出率曲线、
  自强化闭环机制图、质押协议流程图。改 `model.py` 参数重跑即可，图和数字自动自洽。
- 图型挑最能"一眼看懂核心笑点"的：堆叠柱（工时分摊）、函数曲线（摸鱼熵/进度条通胀）、
  机制流程图。配色用公司深蓝 `#12345A` / 红 `#B02424`，别用内刊紫。
- 小坑：宋体缺 en-dash「–」，标签区间用 `0-50%` 或 `0~50%`。
- caption 标注「示意性测算，未经审计」，也可抖个包袱。

### 步骤 4 · 编译成 PDF

**主路径（XeLaTeX）**：跑内置脚本（自动定位 XeLaTeX、把模板里的 Noto 字体换成本机
实际有的中文字体、自动补装缺失宏包、多趟编译解交叉引用）：

```bash
bash "<skill目录>/scripts/compile.sh" "<输出文件夹>/<你的文件名>.tex"
```

**等效路径（本机没有 XeLaTeX 时）**：用 Chrome headless 打印双渲染出的 A4 年报 HTML，
`@page` margin box 会自动生成页眉、页脚与「第 X 页 / 共 Y 页」页码：

```bash
chrome --headless --disable-gpu --no-pdf-header-footer --allow-file-access-from-files \
       --virtual-time-budget=8000 --print-to-pdf="<输出文件夹>/<文件名>.pdf" \
       "file:///<输出文件夹>/<文件名>.html"
```

成功后用 Read 工具把 PDF 各页读出来自检：封面、指标速览、重要提示、目录、释义、
管理层摘要、编号章节、全宽表格、真图、口径说明框、页眉页脚页码、备查文件与免责声明
是否都在位，中文有没有变方块。若报错，脚本会打印 last errors；实在不行把 `.tex` 交给
在线 LaTeX 平台并选 XeLaTeX 编译器。

### 步骤 5 · 交付

给用户：PDF 路径 + 一段简短说明（选了什么流派、招牌黑话是什么、核心笑点在哪、
质押协议的牙齿咬在哪、版式有哪些年报要素），并主动邀请修改
（"想换个更狠的结论 / 加一版风险矩阵 / 把下周计划改成更离谱的承诺都行"）。

## 环境依赖

- **XeLaTeX**（TinyTeX 或 MacTeX）。`compile.sh` 会自动找到它并按需补装宏包。
  没有本地 TeX 环境时，走 Chrome headless 打印 HTML，或把 `.tex` 丢进在线 LaTeX 平台
  （编译器选 XeLaTeX）。
- **Python 3 + matplotlib / numpy**（`make_figs.py` / `make_logos.py` 出图）；
  **pymupdf** 可选，用于逐页自检。
- 模板硬编码了思源(Noto CJK)字体；本机通常没有，`compile.sh` 会自动降级到
  Songti SC / SimSun 等系统中文字体，无需手动改。

## 分寸

戏仿的对象永远是**普遍职场现象**，靠自嘲和共嘲取乐。可以调侃"摸鱼周报文学""开会文化"
"对齐颗粒度"这类共性处境，但不要写成对某个具体同事 / 领导 / 公司的指名道姓攻击；
遇到裁员、绩效、身心健康这类敏感素材，保留人文温度。不要拿真实姓名编造"未完成的工作"——
公司化名和示意性测算就是为此存在的；封面与重要提示里要写明「示意性测算、未经审计、
不指代任何真实企业或个人」。
